## Что внутри
- **Сегодня** — живая «передовица»: какая пара следующая, где, что изменилось на неделе, средний балл, статусы заявок, дедлайны.
- **Расписание** — неделя по дням, аудитория и преподаватель; переносы, отмены и смены аудиторий подсвечены.
- **Учёба** — 100-балльная шкала, из чего сложился балл, сколько не хватает до следующей оценки, стипендия, сессия с обратным отсчётом.
- **Заявки** — справки и заявления онлайн, статусы в виде печатей «Принята → В работе → Готова» с хронологией. (Демо: этапы проходятся автоматически за пару минут.)
- **Уведомления** — новости, дедлайны, изменения; счётчик непрочитанного.
- **Профиль** — ФИО, факультет, направление, курс, группа; светлая/тёмная тема.

## Как устроена защита
- Данные каждого студента зашифрованы **AES-GCM-256** ключом, который выводится из пароля через **PBKDF2-SHA256 (210 000 итераций)** — `tools/build-vault.mjs`.
- **Пароли нигде не хранятся** — ни в открытом виде, ни хешем. Логины хранятся только как SHA-256.
- Без пароля чужие данные **физически не расшифровать**, даже скачав `data/vault.json` или подставив чужой адрес; чужая заявка по URL не открывается.
- Новые заявки сохраняются в браузере тоже в зашифрованном виде.
- В коде нет ключей от сервисов.

## Запуск локально
